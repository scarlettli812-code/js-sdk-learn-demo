# 新品排产助手 V2.1 · 飞书多维表格插件

这是一个基于 Base JS SDK 的飞书多维表格边栏插件。它在当前多维表格内读取需求和每日产能，执行确定性排产，并把结果写回结果表；不需要 Vercel、App Secret 或外部数据库。

## 需要的 5 张表

表名必须保持为：

1. `00_排产控制台`
2. `01_需求与优先级`
3. `02_每日产能`
4. `03_排产结果_by天`
5. `04_区域交付结果`

插件会在运行前核对字段名。字段缺失、控制台参数不合法或没有勾选参与排产的数据时，会停止运行并显示具体原因。

## V2 新增字段

`01_需求与优先级`：

- `交付批次`（文本）
- `批次优先级`（正整数，越小越优先）
- `是否关键首批`（复选框）
- `批次ID`（唯一文本）

`03_排产结果_by天`：

- `关联批次ID`（文本）
- `交付批次`（文本）
- `是否SKU切换`（复选框）
- `切换原因`（文本）

## 已实现的规则

- 只读取“是否参与排产”勾选的数据。
- 一行需求代表一个可独立完成的交付批次。
- 常规候选按需求月份、料号优先级、批次优先级、区域优先级、创建时间排序。
- 当前批次未完成时保持当前 SKU 连续生产。
- 其他 SKU 的关键首批 Ready 后可触发切换；关键首批完成后重新扫描 Ready 批次。
- 关键首批一旦开始会先完成，不被另一个关键首批中途中断。
- 产品之间不共用产能；生产日期不早于最早可生产日。
- 写入结果前会按“产品＋生产日期”独立复核生产数量；一旦超过可排产能，立即中止写入并显示超产日期和数量。
- 同一产品同一天有多条任务时，“当日总产能”只在第一条任务显示，避免在多维表格中被重复求和。
- 批次生产目标按控制台单位向上取整；真实日产能只向下取整数，不按10取整。
- 例如需求3015的生产目标为3020；日产能315可用315，346.5可用346。
- 取整产生的计划余量不覆盖下一条需求。
- 周一至周四生产计入本周可发，周五至周日顺延至下周。
- 同一区域同一月份的多个料号全部覆盖后才标记完成。
- 检测长停产后的恢复生产节点。
- 每次运行生成唯一运行 ID，旧结果保留并取消“是否当前版本”。
- 缺少参数或需求未覆盖时，控制台状态为“有异常”。

## 使用方法

1. 在 `01_需求与优先级` 为每个交付批次录入独立记录，填写唯一批次 ID 并勾选“是否参与排产”。
2. 在 `02_每日产能` 录入产能并勾选“是否参与排产”。
3. 打开插件，等待显示“连接成功，可以开始排产”。
4. 点击“重新排产”。
5. 查看 `03_排产结果_by天` 和 `04_区域交付结果` 的当前视图。

## 本地开发

```powershell
npm.cmd install
npm.cmd test
npm.cmd run dev
```

## 数据安全

插件只使用 Base JS SDK 访问当前打开的多维表格。代码中不包含 App ID、App Secret、访问令牌，也不会把表格数据发送到外部服务器。
